# Personal Homepage Project

A clean, beginner-friendly personal homepage website built using semantic HTML5 and custom CSS3. Designed as an educational project for students learning core web development concepts.

---

**Project Overview**

This project guides students through building a colorful, structured personal profile webpage. It introduces foundational layout structures, typography styling, CSS Flexbox/Grid alignment, list formatting, and gradient background styling.

---

**Page Structure & Features**

- **Navigation Bar**: Top pill-styled navigation links (`Home`, `About`, `Hobbies`, `Activities`, `Goals`) with active link highlighting.
- **Header**: Main title banner featuring custom typography and an underline accent.
- **Profile Cards**: Two-column responsive card container:
- **About Me**: Short intro paragraph paired with a custom hero illustration.
- **My Hobbies**: Unordered list (`<ul>`) detailing personal interests alongside themed artwork.

- **Daily Activities**: Ordered list (`<ol>`) detailing daily routine steps.
- **Daily Schedule Grid**: Structured 2-column grid displaying time slots, activity headings, and short descriptions.
- **Footer**: Centered thank-you message with dynamic year copyright notice.

---

**Technologies Used**

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3**: Linear gradients, border-radius, flexbox layout, CSS grid, and modern color palette variables

**Key Learning Objectives for Students**

1. **Semantic Markup**: Understanding structural HTML tags rather than relying solely on generic `<div>` containers.
2. **CSS Box Model**: Applying `margin`, `padding`, `border`, and `border-radius` to construct clean card UI elements.
3. **Flexbox & Grid Layouts**: Aligning multi-column layouts side-by-side cleanly across different viewport sizes.
4. **Lists**: Distinguishing when to use ordered (`<ol>`) versus unordered (`<ul>`) lists.
5. **Styling & Aesthetics**: Using subtle drop-shadows, soft rounded corners, and pastel background gradients.
